# Desafios da Digital Innovation One

## Descrição

Enviarei desafios mais simples da Digital Innovation One nesse repositório para evitar a criação de múltiplos projetos simples no GitHub. Geralmente esses desafios consistem em arquivos README ou de texto, seja para aprender a prototipar uma ferramenta, estudar recursos de inteligência artificial ou criar documentos específicos. Repositórios separados serão criados para projetos maiores e mais complexos.
